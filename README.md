# tool-selection-labo 🧪

このリポジトリは、社内で利用する各種ツールについて  
**実際に触って検証した結果・比較表・判断理由**を蓄積するための  
ツール選定用「実験室（labo）」です。

---

## このリポジトリの目的

- ツール選定を **属人化させない**
- 比較検討の履歴を **再利用可能な知識**として残す
- 「あとから見返して判断理由が分かる」状態を作る
- 研修・検証・技術調査の成果を一箇所に集約する

---

## 取り扱う内容

- ノーコード / ローコードツールの比較
- AI開発支援ツール・エージェント系ツールの比較
- 同一要件で複数ツールを試した結果の整理
- 実運用を想定した評価（拡張性・スケール・運用負荷 など）
